Tools used:
Unreal Engine 5.2 early access sometimes can be broke, 5.1.1
Visual Studio 2019 , 2022 Community

With the keyboard, use WASD keys to move your character around and spacebar to jump. 
Move mouse to aim, left clicking to shoot

With the gamepad like DualSense, use left thumbstick to move your character around and use X-Button to jump.
Use the right thumbstick to aim, and then press the R2 trigger to shoot.

#KillEmALL
The game is won if you destroy all the enemy shooter characters, without your healthbar 
reaching zero. If your healthbar reaches zero, the game is lost. After each win/lose condition,
the game restarts after 5 seconds.

Certain files were omitted because of their large size and repository storage limitations.
